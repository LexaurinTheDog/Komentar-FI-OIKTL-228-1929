# Varallisuusoikeudellisista oikeustoimista annetun lain (228/1929) kommentaari

Kommentaari suomalaiseen säädökseen: **Laki varallisuusoikeudellisista oikeustoimista 13.6.1929/228** (oikeustoimilaki). Kommentaari kattaa **42 kommentoitavaa yksikköä** — lain 1–42 §:n kaikki pykälät — **2 kommentaarin luvussa**; kunkin pykälän kohdalla esitetään säännöksen sanamuoto sellaisenaan ja sen jälkeen kommentaari.

Tekstin tila: Finlexin ajantasainen lainsäädäntö, versio **20040128** (ajantasaistettu **20.2.2004**, viimeisin lähteessä mainittu muutossäädös L 20.2.2004/128, voimaan 1.9.2004).

## Menetelmä

Kommentaari on laadittu **yksinomaan paikallisten aineistojen perusteella** (Finlexin avoimen datan ajantasainen säädösteksti ja sen metatiedot), ilman kaupallisia oikeudellisia tietokantoja. Säännösten sanamuoto on siirretty lähteestä koneellisesti ja sanatarkasti. **Oikeuskäytäntö ei sisälly tähän versioon** — se lisätään erillisessä vaiheessa.
